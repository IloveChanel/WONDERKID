# Asset Directory

The art pipeline is intentionally modular.

- `reference/` = visual direction and concept references
- `characters/` = production character assets
- `world/` = backgrounds, terrain, structures and environment
- `props/` = gameplay objects
- `ui/` = UI artwork and icons

Reference boards are not production sprites. Production art should be separated into reusable transparent sprites, tile sets, background scenes, or animation sheets as specified by the manifest.
